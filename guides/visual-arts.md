# **Visual Communication**

| Course Title | Visual Communication |
| :---- | :---- |
| **Department** | Visual Arts |
| **Course Description** | In Visual Communication, students will be learning how we can use computer-based technology to create expressive and unique pieces of visual art. Sometimes we will be using technology to help us plan for more traditional art forms, while other times we will be using traditional art materials and methods to prepare for a finished product created with software.
